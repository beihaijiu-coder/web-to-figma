# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues at `beihaijiu-coder/web-to-figma`. Use the `gh` CLI for all issue operations.

## Conventions

- Create issues with `gh issue create`.
- Read issues with `gh issue view <number> --comments`.
- List issues with `gh issue list`, filtering by state and label as needed.
- Add or remove workflow labels with `gh issue edit`.
- A request to publish a PRD means creating a GitHub Issue.
