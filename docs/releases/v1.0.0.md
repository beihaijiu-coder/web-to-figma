Web to Figma 1.0.0 is the first public local-first release. It captures a rendered page or selected element in Chrome and imports the result into Figma as editable layers whenever possible.

## English

### Included

- Full-page and selected-element capture in Chrome.
- Editable Figma text, containers, borders, images, and common layouts.
- Local visual fallbacks for complex Canvas, video, and iframe regions.
- Visual-fidelity and editable-layout import modes.
- Local clipboard transfer without an account, API, or cloud upload.

### Installation

1. Download and extract both ZIP files attached to this release.
2. In Chrome, open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select the extracted Chrome directory.
3. In the Figma desktop app, choose **Plugins → Development → Import plugin from manifest**, then select `manifest.json` from the extracted Figma directory.

`SHA256SUMS.txt` contains the checksums for both archives.

### Current limits

The release does not convert animation, video playback, or interaction logic into Figma prototype behavior. A capture represents one rendered Chrome viewport state and does not infer other responsive breakpoints.

## 简体中文

### 包含内容

- 在 Chrome 中捕获完整页面或选中元素。
- 将文字、容器、边框、图片和常见布局导入为可编辑的 Figma 图层。
- 将 Canvas、视频和 iframe 等复杂区域按局部保留为视觉结果。
- 提供视觉还原优先和可编辑布局优先两种导入模式。
- 通过本地剪贴板传递数据，不需要账号、API 或云端上传。

### 安装

1. 下载并解压本版本附带的两个 ZIP 文件。
2. 在 Chrome 中打开 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，然后选择解压后的 Chrome 目录。
3. 在 Figma 桌面端选择 **Plugins → Development → Import plugin from manifest**，然后选择解压后 Figma 目录中的 `manifest.json`。

`SHA256SUMS.txt` 包含两个压缩包的校验值。

### 当前限制

本版本不会将动画、视频播放状态和交互逻辑转换为 Figma 原型行为。一次捕获只对应 Chrome 中的一个实际渲染状态，不会自动推断其他响应式断点。
