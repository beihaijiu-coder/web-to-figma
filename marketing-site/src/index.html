Three moves

不需要先学一套新工具。

工作流只围绕三个动作：捕获、回到 Figma、导入。没有账号步骤，也没有中间文件。

  1. 01

    在页面上捕获

    选择完整页面，或用选取工具只捕获一个组件。

  2. 02

    结果自动复制

    捕获数据保存在本地剪贴板，不经过账号或云端服务。

  3. 03

    一键导入图层

    回到 Figma，点击“导入最近捕获”即可开始创建图层。

One obvious action

打开插件，就知道下一步做什么。

最常用的“导入最近捕获”始终在最前面。布局偏好与字体替代收进次级设置，不打断默认流程。

转换会尽可能使用 Figma 原生节点；只有遇到无法稳定还原的复杂局部时，才保留那一小块的视觉结果。

Install locally

先用本地安装跑通一次。

当前版本从 GitHub 安装。只需要下载一份仓库，不需要配置 API 或登录账号。

打开 GitHub 仓库 ↗
  1. 1

    下载仓库

    在 GitHub 选择 Code → Download ZIP，然后解压。

  2. 2

    加载 Chrome 扩展

    打开 chrome://extensions，开启开发者模式，选择 chrome-extension 目录。

  3. 3

    导入 Figma 插件

    在 Figma 桌面端的开发插件中，选择 figma-plugin/manifest.json。

  4. 4

    捕获第一个页面

    在 Chrome 捕获页面，回到 Figma 点击“导入最近捕获”。

Questions

开始前应该知道的事。

必须登录或连接 API 吗？

不必。当前版本只使用本地剪贴板：Chrome 捕获后，直接回到 Figma 导入。

导入后是否所有内容都能编辑？

常规文字、容器、按钮和图片会尽可能转为原生节点。无法可靠拆解的复杂局部会保留视觉结果，但不会将整页变成一张图。

可以一次生成所有响应式断点吗？

不可以。一次捕获对应当前 Chrome 视口下的一个真实状态；需要多个断点时，请分别调整宽度后捕获。

为什么需要同时安装两个工具？

Chrome 扩展负责读取当前页面状态，Figma 插件负责在画布中创建图层；两者通过本地剪贴板交接。
